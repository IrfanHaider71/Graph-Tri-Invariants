Manuscript
----------
A Graph-Based Framework for Molecular Property Prediction from Topological Descriptors

Authors:  Irfan Haider et al.

Journal: Journal of Computer-Aided Molecular Design
Status: Manuscript under revision for resubmission.

Description
-----------
This repository contains the source code for molecular-graph construction,
graph energy, the Schultz index, degree entropy, regression analysis,
cross-validation, applicability diagnostics, numerical conditioning,
runtime assessment, and the associated figures described in the manuscript.
